# RG_FastFood

2D OpenGL project in C++ simulating a fast food ordering scenario.

## Features (Current)

- Start screen with "Order" button.
- Custom cursor shaped like a spatula.
- Clickable button transitions to cooking state.
- Placeholder raw pattie displayed when cooking starts.
- Fullscreen mode with 75 FPS frame limiter.

## Project Setup

- C++ with OpenGL 3.3 Core Profile.
- Uses GLEW and GLFW (NuGet packages).
- Textures stored in `res/` folder.
- Shaders in project root (`rect.vert`, `rect.frag`).
- Utilities in `Util.h` / `Util.cpp`.

## How to Run

1. Clone repo.
2. Open in Visual Studio 2022.
3. Make sure NuGet packages (GLEW, GLFW) are restored.
4. Build and run the project.
5. Use mouse to interact with the start menu.
